# MVP на `oncomap-abai.kz/quality/`

Портал работает под префиксом `/quality/`. На главной странице Oncomap добавьте пункт:

```html
<a href="/quality/">Тестирование и обучение</a>
```

## Первый запуск

1. В `.env` задайте `DJANGO_DEBUG=0`, длинный случайный `DJANGO_SECRET_KEY`, пароль PostgreSQL, `DJANGO_ALLOWED_HOSTS=oncomap-abai.kz,www.oncomap-abai.kz` и `DJANGO_CSRF_TRUSTED_ORIGINS=https://oncomap-abai.kz,https://www.oncomap-abai.kz`.
2. Выполните `docker compose up -d --build`.
3. Только для демонстрационной базы один раз выполните `docker compose exec web python manage.py seed_demo`. Повторный seed при каждом запуске отключён.
4. В основном Nginx сайта проксируйте `/quality/` на порт контейнера и сохраните исходный URI. Статические файлы и PDF также обслуживаются под `/quality/static/` и `/quality/media/`.

## История и отчёт

Каждое завершённое или исчерпавшее попытки назначение хранится отдельным циклом. Повторное назначение создаёт новый цикл и не изменяет прошлые даты и оценки. Если активный цикл уже существует, повторное действие только обновляет его срок и правила, не дублируя уведомление.

Excel не хранится на диске и не кэшируется: при каждом нажатии «Скачать Excel» он заново строится из актуальной базы. Одна строка соответствует одной попытке; назначения без попыток также попадают в файл. Фильтры страницы применяются и к выгрузке. Руководитель видит только сотрудников своего отдела.

Email не используется. Уведомление о незавершённых назначениях показывается колокольчиком внутри портала.

## Что обязательно перед рабочей эксплуатацией

- заменить демонстрационные пароли и не публиковать тестовые учётные записи;
- включить HTTPS и ежедневные зашифрованные резервные копии PostgreSQL и каталога `media` вне VPS;
- запретить загрузку любых форматов кроме PDF, добавить проверку MIME/размера и антивирусную проверку файлов;
- добавить журналирование изменений курсов, назначений и пользователей, срок хранения журнала и процедуру восстановления;
- провести нагрузочный тест на фактическом тарифе VPS; для MVP достаточно PostgreSQL, 3 Gunicorn workers и Nginx, но PDF лучше отдавать Nginx, а не Django;
- не размещать в системе сведения о пациентах: портал предназначен только для обучения сотрудников.

## Основные устранённые временные решения

- миграции больше не генерируются автоматически при старте production-контейнера;
- демо-данные не перезаписываются при перезапуске;
- завершённая история не стирается повторным назначением;
- ссылки, вход, статика, PDF и админ-панель учитывают префикс `/quality/`;
- версия Django ограничена поддерживаемой LTS-веткой 5.2.
